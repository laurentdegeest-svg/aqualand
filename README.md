# Aqualand — site vitrine + diagnostic

Site statique (HTML/CSS/JS, aucune installation) prêt pour GitHub Pages.

## Modifier les réglages
Tout se règle dans **config.js** : e-mail de réception des diagnostics, coordonnées,
réduction, prix des abonnements, hypothèses du simulateur.

## Recevoir les diagnostics (avec photos)
Mettez votre adresse dans `emailReception` (config.js). Les demandes passent par FormSubmit.co.
La 1re demande envoie un e-mail d'activation à confirmer une seule fois.

## Mettre en ligne (GitHub Pages)
Settings → Pages → Branch `main` / root → Save. Le site sera sur `https://<compte>.github.io/aqualand/`.
